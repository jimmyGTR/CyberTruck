# Catálogo Web Interactivo

Catálogo web responsivo con conexión directa a WhatsApp, reproducción de video en modal y animaciones al desplazarse.

## Estructura de archivos
- `index.html`: Estructura principal y ventana modal de video.
- `datos.js`: Base de datos de productos y número de contacto.
- `app.js`: Renderizado dinámico de tarjetas, enlaces de WhatsApp y observador de scroll.
- `estilos.css`: Diseño responsivo, fondo animado y transiciones.
- `img/` y `videos/`: Carpetas para los recursos multimedia.
